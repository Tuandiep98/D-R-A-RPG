# Fantasy UI frames

Kenney Fantasy UI Borders 1.0 (CC0), https://kenney.nl/assets/fantasy-ui-borders.
Generated by `pnpm assets:fantasy-ui` (`tools/asset-processor/fantasy-ui.ts`):
only the palette is recoloured, pixels are unchanged. Do not edit by hand.

| File                 | Source (`PNG/Default/…`)                             | Use                        |
| -------------------- | ---------------------------------------------------- | -------------------------- |
| `panel.png`          | `Panel/panel-000.png`, dark                          | windows, HUD frames        |
| `slot.png`           | `Transparent center/panel-transparent-center-011.png`, grey | skill/item slots    |
| `slot-active.png`    | same, white (unmodified)                             | selected slot              |
| `button.png`         | `Transparent center/panel-transparent-center-009.png`, grey | secondary buttons   |
| `button-primary.png` | `Panel/panel-009.png`, white (unmodified)            | primary / active segment   |
| `divider.png`        | `Divider Fade/divider-fade-000.png` (unmodified, 96×22) | zone banner             |

48 × 48 px on a 2 px grid, 16 px nine-slice corners: draw with
`border-image-width` 8 / 16 / 32 px only. Imported by `fantasy-glass.css` so Vite
bundles them for root and subpath deployments without a media build.
